# Weekly Planner

An installable web app (PWA) for energy-based weekly planning with study schedule integration. Plain HTML with a service worker for offline use.

```bash
npm install
npm run dev      # wrangler pages dev .
npm run deploy   # wrangler pages deploy .
```

Pushes to main deploy to Cloudflare Pages through [.github/workflows/deploy.yml](.github/workflows/deploy.yml).
